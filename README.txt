JARVIS — СТАТИЧЕСКИЙ САЙТ
========================

Файлы сайта:
- index.html — главная страница
- styles.css — оформление в тёмном неоново-синем стиле
- script.js — небольшой клиентский скрипт
- assets/jarvis.ico и assets/jarvis-icon.png — иконка
- downloads/ — сюда положить собранный Jarvis.exe

ПРОВЕРКА ЛОКАЛЬНО
1. Распакуйте папку.
2. Положите готовый Jarvis.exe в папку downloads.
3. Откройте index.html в браузере.

ПУБЛИКАЦИЯ
Загрузите содержимое папки Jarvis_Site на статический хостинг (например, GitHub Pages, Netlify или собственный веб-сервер).
Чтобы кнопки скачивания работали, файл должен быть доступен по пути downloads/Jarvis.exe.

ВАЖНО
В архиве сайта нет готового Jarvis.exe — сборку приложения нужно выполнить отдельно.
Не публикуйте API-ключи, личную историю, кэш или другие приватные данные в открытом доступе.
